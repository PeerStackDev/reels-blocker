# ReelsBlocker

ReelsBlocker — Android-приложение для ограничения потребления короткого видеоконтента и бесконечной прокрутки ленты.


## :dart: Цель проекта

Помочь пользователям контролировать время, проводимое в социальных сетях и сервисах с короткими видео.

Приложение позволяет блокировать короткие видео и элементы бесконечной ленты в поддерживаемых приложениях.

## :gear: Основные возможности

На текущем этапе реализованы:

- блокировка коротких видео;
- блокировка бесконечной прокрутки;
- поддержка нескольких приложений;
- настройка режимов блокировки;
- пользовательский интерфейс на Jetpack Compose;
- работа через Android Accessibility Service.
